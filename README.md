# Habbiter

습관을 등록하고 날짜별 이행 여부를 기록하여, 습관을 꾸준히 실천할 수 있도록 도와주는 Windows 데스크톱 습관 관리 프로그램입니다.

## 📌 프로젝트 소개

**Habbiter**는 사용자가 습관을 등록하고, 달력을 통해 특정 날짜의 습관 이행 여부를 확인할 수 있도록 만든 습관 관리 프로그램입니다.

각 습관은 `O / X`로 이행 여부를 직접 기록할 수 있으며, 하루에 등록된 모든 습관을 완료하면 해당 날짜를 완료한 날로 계산합니다.

데이터는 별도의 데이터베이스를 사용하지 않고 **CSV 파일을 이용하여 로컬 환경에 저장**합니다.

## ✨ 주요 기능

* 습관 추가
* 습관 삭제
* 날짜별 습관 이행 여부 확인
* 습관 이행 여부를 `O / X`로 변경
* 달력을 이용한 날짜 선택
* 선택한 날짜의 습관 기록 조회
* 하루의 모든 습관 완료 여부 확인
* 연속 완료 일수 계산

## 🖥️ 실행 환경

* **운영체제:** Windows
* **언어:** C++20
* **개발 환경:** Visual Studio
* **GUI:** Windows API / Win32
* **데이터 저장:** CSV 파일
* **데이터베이스:** 사용하지 않음

## 💾 데이터 저장 형식

Habbiter는 데이터를 **CSV(Comma-Separated Values) 파일**로 저장합니다.

사용되는 데이터 파일은 다음과 같습니다.

```text
Habits.csv
Records.csv
```

### 1. Habits.csv

등록된 습관의 이름과 습관이 추가된 날짜를 저장합니다.

#### 형식

```text
습관 이름,추가 날짜
```

#### 예시

```csv
운동하기,2026-09-01
독서하기,2026-09-03
영어 공부,2026-09-10
```

| 컬럼    | 설명                           |
| ----- | ---------------------------- |
| 습관 이름 | 사용자가 등록한 습관의 이름              |
| 추가 날짜 | 해당 습관이 등록된 날짜 (`YYYY-MM-DD`) |

습관은 추가된 날짜부터 기록에 적용되며, 이전 날짜의 기록에는 소급하여 적용하지 않습니다.

### 2. Records.csv

날짜별 습관 이행 여부와 해당 날짜의 전체 완료 여부를 저장합니다.

#### 형식

```text
날짜,전체 완료 여부,습관 이름=true|습관 이름=false
```

#### 예시

```csv
2026-09-28,true,운동하기=true|독서하기=true
2026-09-29,false,운동하기=true|독서하기=false
2026-09-30,true,운동하기=true|독서하기=true
```

| 컬럼        | 설명                              |
| --------- | ------------------------------- |
| 날짜        | 해당 기록의 날짜 (`YYYY-MM-DD`)        |
| 전체 완료 여부  | 해당 날짜의 모든 습관을 완료했는지 여부          |
| 습관 이행 데이터 | 각 습관의 완료 여부를 `true / false`로 저장 |

습관별 이행 데이터는 `|`를 기준으로 구분합니다.

예를 들어:

```text
운동하기=true|독서하기=false
```

는 다음과 같은 의미입니다.

```text
운동하기 → 완료
독서하기 → 미완료
```

## 🔄 데이터 처리 과정

프로그램을 실행하면 저장된 CSV 데이터를 불러옵니다.

```text
프로그램 실행
     ↓
CSV 데이터 로드
     ↓
달력에서 날짜 선택
     ↓
선택한 날짜의 습관 기록 표시
     ↓
습관 O / X 선택
     ↓
완료 여부 확인
     ↓
Records.csv 갱신
     ↓
화면 갱신
```

데이터가 존재하지 않거나 파일을 읽거나 저장하는 과정에서 오류가 발생하면 안내 메시지를 표시합니다.

## 📅 연속 완료 일수

하루의 모든 습관을 완료한 경우 해당 날짜를 완료한 날로 계산합니다.

연속 완료 일수는 **오늘을 기준으로 계산**하며, 중간에 완료하지 않은 날짜가 있으면 연속 기록이 종료됩니다.

예를 들어:

```text
09-27  전체 완료  ✓
09-28  전체 완료  ✓
09-29  전체 완료  ✓
09-30  미완료      ✗
10-01  전체 완료  ✓
```

오늘이 `10-01`이라면 연속 완료 일수는 `1일`입니다.

## ⚠️ 예외 처리

Habbiter는 잘못된 입력이나 데이터 오류가 발생했을 때 프로그램이 비정상적으로 종료되지 않도록 안내 메시지를 출력합니다.

주요 예외 상황은 다음과 같습니다.

* 빈 습관 이름 입력
* 이미 등록된 습관 추가
* 존재하지 않는 데이터 조회
* CSV 파일 읽기 실패
* CSV 파일 저장 실패

## 🔒 개인정보 및 보안

Habbiter는 로컬 환경에서 동작하며 별도의 서버나 데이터베이스를 사용하지 않습니다.

사용자의 습관 데이터는 로컬 CSV 파일에 저장됩니다.

따라서 CSV 파일을 다른 위치로 복사하면 데이터를 백업할 수 있으며, 기존 CSV 파일을 복원하여 데이터를 복구할 수 있습니다.

## 📄 라이선스

현재 별도의 오픈소스 라이선스를 적용하지 않은 개인 프로젝트입니다.
